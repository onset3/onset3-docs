# ONSET3 Docs

Public documentation for ONSET3. The 57 source pages were imported from onset3/OnSet3/docs.

Edit documentation under docs/. Changes pushed to main build and deploy the website automatically.

## First publication

Enable GitHub Pages in Settings > Pages: Deploy from a branch, gh-pages, /(root), after the first workflow succeeds.

## Local preview

pip install -r requirements.txt

mkdocs serve
