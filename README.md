## Product status

ONSET3 is live and actively developed. Current product areas include published project profiles, launch information and countdowns, watchlists, personal calendars, and project submission.

Personal allowlist management, NFT portfolios, Events, Campaigns, and market intelligence remain planned. Notification delivery is not advertised here as a live service. Status labels describe availability, not release commitments.

## About this repository

This repository contains public product documentation, not the proprietary application source. No public developer API or SDK is currently promised by these docs.

Documentation lives under `docs/`. Follow ONSET3 on X for product updates. Documentation corrections can be proposed through this repository's pull requests; acceptance remains subject to review.

## Local documentation preview

```sh
pip install -r requirements.txt
mkdocs serve
```
