# Events

> **Status: Roadmap**

Events represent scheduled activities around a project or community.

Potential event types include:

- mint;
- reveal;
- AMA;
- X Space;
- community call;
- claim;
- drop;
- meetup;
- conference;
- tournament;
- custom event.

The initial event model is intentionally lightweight: project, title, date/time, destination and calendar action.
