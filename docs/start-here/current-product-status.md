# Current Product Status

> **Status: Living Document**

ONSET3 separates documentation by product maturity.

| Status | Meaning |
| --- | --- |
| **Current** | Implemented functionality in the current product |
| **In development** | Work underway; not yet an available product capability |
| **Beta** | Available but still being refined |
| **Next** | Near-term product work |
| **Roadmap** | Approved direction, not yet a current capability |
| **Future** | Longer-term product concept |

The current product foundation is centered on project and launch discovery, project profiles, launch information, tracking, project submission and verification workflows.
