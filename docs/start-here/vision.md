# Vision

> **Status: Product Direction**

ONSET3 aims to become an operating layer for the NFT ecosystem.

The product direction follows four stages:

1. **Discover** — find projects, launches and relevant activity.
2. **Track** — organize watchlists, allowlists, launch dates and reminders.
3. **Participate** — join events and campaigns around projects.
4. **Understand** — use portfolio and intelligence tools to understand personal activity, collector behavior and the broader NFT market.

The goal is not to add every possible Web3 feature. Each layer should make NFT discovery and decision-making clearer.
