# ONSET3

**Discover What's Next in NFTs.**

ONSET3 is an NFT discovery, tracking, participation, portfolio and intelligence platform designed to make fragmented NFT information easier to discover, organize and understand.

The product begins with launch discovery and tracking, then expands through events, campaigns, portfolio tooling and an intelligence layer for NFT markets and collector behavior.

> **Documentation principle:** current capabilities, near-term roadmap items and future concepts are kept clearly separated throughout these docs.
