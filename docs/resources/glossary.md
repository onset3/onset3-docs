# Glossary

> **Status: Current**

**Allowlist / WL** — Access granted to a specific launch stage.

**Watchlist** — A personal state meaning the user is interested in a project.

**My WL** — A personal state meaning the user has allowlist access.

**Project** — The persistent identity of a project on ONSET3.

**Launch** — A time-based mint, release, claim or related launch activity.

**Event** — A scheduled project or community activity.

**Campaign** — Structured participation containing tasks and progress.

**GTD** — Guaranteed allocation stage.

**FCFS** — First come, first served stage.

**Public** — Publicly available launch stage.

**Reveal** — Publication of previously hidden collection information or media.

**Claim** — A time-based action allowing eligible users to receive an asset or benefit.

**Verified Project** — A project whose specified information has been reviewed by ONSET3.

**Onchain Verified** — A separate verification state based on supported blockchain information.

**Signal** — A future data-derived indicator describing measurable market or behavior change.
