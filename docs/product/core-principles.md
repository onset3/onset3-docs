# Core Product Principles

> **Status: Current**

ONSET3 follows a small set of product rules:

- **Discovery first.** Information should be useful before requiring deep interaction.
- **Time matters.** Launches and events are time-sensitive and should be presented accordingly.
- **Project and event identity are separate.** One project can have multiple launches and events.
- **Official destinations must be clear.** External links should never be visually ambiguous.
- **Tracking should be personal.** Interest, allowlist access and calendar intent are different states.
- **Verification is informational, not endorsement.**
- **Roadmap features must not be presented as live.**
- **Crypto complexity should not be added unless it improves the actual user task.**
