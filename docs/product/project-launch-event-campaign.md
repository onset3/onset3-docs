# Project vs Launch vs Event vs Campaign

> **Status: Current + Roadmap**

These concepts are intentionally separate.

| Entity | Purpose |
| --- | --- |
| **Project** | Persistent project identity |
| **Launch** | Time-based release or mint activity |
| **Event** | Scheduled project/community activity |
| **Campaign** | Structured user participation with tasks |

A single project can therefore contain multiple launches, multiple events and multiple campaigns over time.

This prevents ONSET3 from creating duplicate project profiles every time something new happens.
