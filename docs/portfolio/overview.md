# Portfolio Overview

> **Status: Next**

Portfolio brings a collector's NFT inventory into ONSET3 without changing the account system into wallet-based authentication.

The portfolio roadmap has three phases:

1. **Holdings** — wallets, NFTs, collections and chain grouping.
2. **Activity** — mint, buy, sell, receive and send history.
3. **Analytics** — cost basis, realized/unrealized performance and valuation where reliable data exists.

Each phase should be useful independently.
